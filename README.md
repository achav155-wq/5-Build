# 5-Build
Module 5 Build
This project is a responsive website built using semantic and validated HTML. CSS is responsive and there is No Javascript. It incorporates CSS Grid and Flexbox. It follows a mobile-first design and uses media queries to adapt the layout for larger screen sizes. The site showcases content related to film events for The Film Collective.

Pages Included
-Home (index.html)
-Screenings (screenings.html)
-Workshops (workshops.html)
-Collaborations (collaborations.html)
